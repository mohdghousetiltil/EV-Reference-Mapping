# EV-Reference-Mapping
### [🔗 EV Reference Generator for In-Wheel Motor Vehicles]()
*   Researched and developed an adaptive motor speed reference generator to ensure stability and safe tire slip for electric vehicles during cornering.
*   Engineered a co-simulation environment between MATLAB/Simulink and CarSim, modeling complex vehicle dynamics (aerodynamics, suspension, combined slip theory).
*   Designed a novel control algorithm using contraction mapping and Pacejka-like curves, enabling automatic speed adjustment without prior knowledge of road conditions.
*   Built and validated a high-fidelity co-simulation environment using MATLAB/Simulink and CarSim, incorporating complex vehicle dynamics often neglected in control design.
*   Key Outcome: Achieved a safe operating condition close to the maximum torque-slip characteristics, preventing wheel slip and ensuring vehicle stability under uncertain road conditions.
*   `MATLAB` `Simulink` `Data Analysis & Simulation` `CarSim` `Control Theory` `Systems Modeling` `Algorithm Design` `Vehicle Dynamics`
